# Hikariuni

写真の中の光源を見つけて、クロスフィルターのような**光芒**（光の筋）を描く、Affinity 向けのフィルタープラグイン。

名前は **光（hikari）＋ ウニ（uni）**。光源から伸びる光芒が、ウニのトゲのように見えることから。

## 特長

- 明るさだけでなく**周囲とのコントラスト**で光源を判定し、星や水面のきらめきなど、点状の光にだけ光芒を描く。
- 花びらや雲などの大きな明るい物体、物の縁などの細長い部分は自動で除外する。
- 光芒の本数・角度・長さ・太さ・柔らかさ・虹色のにじみ・ハローを、プレビューを見ながら調整できる。プレビューは Affinity と同じ操作で拡大・移動できる。
- 自動検出に加えて、プレビューをクリックして光源を足したり、Alt+クリックで外したりできる。
- 光芒だけを透過で書き出すモードがあり、別レイヤーにして重ねれば後から調整できる。
- 前回 OK した設定を覚えておき、次回の初期値にする。
- RGB / グレースケール、8bit / 16bit に対応。

## 動作環境

- Windows 10 / 11（x64）
- AVX2 対応の CPU（Intel Haswell・AMD Excavator 以降。おおむね 2013 年以降の CPU）
- Photoshop 互換プラグインに対応した Affinity

## ビルド

### 必要なもの

- Visual Studio 2026（「C++ によるデスクトップ開発」）
- Adobe Photoshop Plug-in SDK
  - リポジトリには含めていない。Adobe のライセンスに同意したうえで各自入手すること。

### 手順

1. SDK の `pluginsdk` フォルダを環境変数 `PHOTOSHOP_SDK_PATH` に設定する。
   ```bat
   setx PHOTOSHOP_SDK_PATH "C:\path\to\photoshop-cpp-sdk\pluginsdk"
   ```
2. 次のどちらかでビルドする。
   - Visual Studio 2026 で `src/hikariuni.slnx` を開き、構成を **Release / x64** にしてビルド（テスト用の GoogleTest は NuGet で自動復元される）。
   - 「Developer Command Prompt for VS 2026」から MSBuild でビルド。
     ```bat
     msbuild src\hikariuni.slnx -restore -p:RestorePackagesConfig=true -p:Configuration=Release -p:Platform=x64
     ```
3. `src/x64/Release/hikariuni.8bf` ができる。テスト（`hikariuni.test`、GoogleTest）もビルドのたびに実行され、VS のテストエクスプローラーからも実行できる。

### フォルダ構成

```
src/
  hikariuni.slnx      ソリューション
  hikariuni/          プラグイン本体（.vcxproj、ソース、PiPL とダイアログの定義）
  hikariuni.test/     光源の検出・描画のテスト
docs/
  spec.md             仕様
```

## Affinity への導入

1. `hikariuni.8bf` を好きなフォルダに置く。
2. Affinity の設定で「Photoshop プラグイン」を開く。
   - **Plugin Search Folders** に、`.8bf` を置いたフォルダを追加する。
   - **Allow Unknown Plugins to be used** をオンにする。自作のプラグインは Affinity の動作確認リストに入っていないので、オフのままだと読み込まれない。
3. Affinity を再起動すると、フィルターメニューのプラグインの中に **Hikariuni** が出る。

## 使い方

1. 光芒を付けたいピクセルレイヤーを選び、フィルターメニューから **Hikariuni...** を実行する。
2. ダイアログのプレビューを見ながらスライダーか数値入力（Enter かフォーカス移動で確定）で調整し、OK で適用する。ウィンドウは大きさを変えられ、次回も同じ大きさで開く。

| スライダー | 効果 |
|---|---|
| 明るさ | これより暗い画素は光源にしない |
| コントラスト（周囲との差） | 周囲よりどれだけ明るければ光源とみなすか。上げると光源が減る |
| 最大サイズ | これより大きい明るい領域（花・雲など）は光源にしない |
| 最大個数 / 最小間隔 | 光芒を付ける数と、光源どうしの最小の間隔 |
| 光芒の本数 / 角度 / 長さ / 太さ | 光芒の形 |
| 柔らかさ | 0 で縁がくっきり、1 で幅が広がってふんわりした光の筋になる |
| 強さ / 虹色（分散） / ハロー | 明るさ、先端の虹色のにじみ、中心のぼんやりした光 |

プレビューの操作（Affinity と同じ）:

| 操作 | 効果 |
|---|---|
| Ctrl+ホイール | カーソルの位置を中心に拡大縮小 |
| ホイール / Shift+ホイール | 上下 / 左右に移動 |
| 中ボタンのドラッグ、スクロールバー | 移動 |
| 「全体表示」ボタン | 画像全体が収まる拡大率に戻す |
| 「テーマ」ボタン | ダーク / ライトを切り替える（既定はダーク。設定は次回も残り、「初期値に戻す」では変わらない） |
| クリック | その位置に光源を追加する（大きさと色は、その付近の明るい画素から自動の光源と同じように決める） |
| Alt+クリック | 近くの光源を外す（手動で足した光源は消える） |

- 水面のきらめきに光芒を付けたくないときはコントラストを上げるか最大個数を下げ、星にもっと付けたいときは最小間隔を下げる。自動検出で拾えない・拾いすぎた光源はクリックで直す。
- 手動の追加・除外はその画像だけのもので、次回には残らない。「初期値に戻す」でも消える。
- 選択範囲があれば、その中にだけ光芒を描く。
- 透明な部分には光芒が出ない。背景のある画像レイヤーに使う。
- プラグインのフィルターは画素を直接書き換える（Affinity のライブフィルターのように後から再調整はできない）。元に戻せるよう、レイヤーを複製してから使うとよい。

### 光芒だけを別レイヤーにする（後から調整したいとき）

1. 画像レイヤーを複製する。
2. 複製したレイヤーに Hikariuni を **「光芒のみ出力（透過）」をオン** にして適用する（光芒以外が透明になる）。
3. そのまま（描画モード「通常」）でも重なる。描画モードを **スクリーン** か **加算** にすると、光が足し合わされてより明るく重なる。

不透明度・マスク・位置などを Affinity 側で後から調整できる。透明度を持たないレイヤーでは黒背景で書き出されるので、描画モードをスクリーンか加算にする。
